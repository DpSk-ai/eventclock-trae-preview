# EventClock V2 - TRAE Hackathon Edition

面向 **四川大学 TRAE on Campus AI Coding Hackathon** 现场的高精度倒计时与路演计时应用。基于绝对时间戳计算，支持活动管理、提醒、独立路演投影大屏、沉浸式主大屏与本地持久化，可作为纯静态站点部署。

**视觉升级**：TRAE 黑客松专属设计，代码粒子流、发光网格、数据脉冲动画，明确的品牌标识与阶段信息，一眼认出"TRAE 黑客松"。

默认活动：**四川大学 TRAE on Campus AI Coding Hackathon**，2026-11-28（周六）北京时间 14:10–17:10，可随时编辑。

## 功能亮点

### 🎯 TRAE 黑客松专属视觉
- **品牌标识**：页面与大屏清晰显示 "TRAE on Campus"、"AI Coding Hackathon"、"四川大学"
- **原创视觉元素**：代码粒子流、发光网格、数据脉冲动画（纯 CSS/SVG，可关闭）
- **明确倒计时目标**：清楚标注"正在倒计时：距离目标时间 XXX"，不会混淆活动开始/结束与倒计时目标
- **当前阶段显示**：活动类型、进行状态一目了然
- **可配置品牌**：主题文案、阶段名称在 `src/config/branding.ts` 中可编辑

### 📺 路演计时投影大屏
- **独立全屏模式**：专为路演设计的投影大屏，与活动倒计时大屏分离
- **队伍名称可编辑**：显示参赛队伍/选手名称，实时更新
- **清晰状态指示**：剩余时间超大显示，超时后显示负数计时与红色提示
- **现场控制**：大屏内可暂停、继续、重置，支持鼠标唤醒控件
- **一键进入**：从路演计时面板点击全屏按钮直接投影

### 活动倒计时
- 基于绝对时间戳，展示天 / 时 / 分 / 秒，支持「天 · 时 · 分 · 秒」「总时 · 分 · 秒」「紧凑」三种显示模式
- **明确目标时间**：界面标注"正在倒计时：距离目标时间"，区分活动结束时间和倒计时目标
- 开始前 / 进行中 / 已结束三态，归零后停止并展示结束提示
- 刷新、切回标签页、系统休眠恢复后按当前时间重新校准，不做累加计时
- 临近截止的分级警示（10 分钟 / 5 分钟 / 1 分钟 / 最后 10 秒）

### 活动管理
- 创建、编辑、删除、复制、切换活动
- 活动类型、提醒阈值、状态一览、每条活动的倒计时
- JSON 导入 / 导出（含活动、设置与数据版本）
- LocalStorage 完整持久化；支持损坏数据自动恢复、版本校验与损坏原始数据备份

### 提醒
- 预设 10 / 5 / 1 分钟、最后 10 秒、截止时刻，支持自定义分钟阈值（最多 8 个）
- 界面通知 + 可开关的提示音
- 声音遵守浏览器自动播放限制，仅在用户与页面交互后播放
- **刷新处理优化**：避免页面恢复时连续弹出多个旧提醒

### 大屏演示（活动倒计时）
- 一键进入全屏（Fullscreen API），失败时仍可展示全屏覆盖层
- 沉浸模式：自动隐藏控件，移动鼠标/触摸后重新显示
- 超大数字，按 1080P / 2K / 4K / 投影自适应，支持手机与 16:9
- **TRAE 品牌元素**：显示主办方、活动名称、阶段状态
- 快捷键：`F`、`I`、`←` / `→`、`Esc`
- 大屏内可直接切换上一条 / 下一条活动与显示模式

### 独立路演计时
- 3 分钟、5 分钟与自定义时长（0.5–240 分钟）
- **队伍名称输入**：可设置当前路演的队伍/选手名称
- **投影大屏按钮**：一键打开路演专用全屏，显示队伍名、剩余时间、状态
- 开始 / 暂停 / 继续 / 重置，超时提醒与负数计时
- 使用绝对结束时间，刷新或后台恢复后不漂移
- 与活动倒计时状态完全隔离，互不影响

### 设置
- 深色 / 浅色主题（深色优先）
- 倒计时显示模式、数字格式（补零 / 自然）
- 时区（默认北京时间，可跟随系统或选择常用时区）
- 界面动效、提醒总开关、声音开关
- 数据导出 / 导入 / 恢复默认设置 / 清空所有数据

### 🕐 时间校准提示
- **自动检测时间偏差**：页面加载时检测本地时间与网络时间差异
- **明确纯前端限制**：清楚说明"纯静态前端无法自动纠正设备时钟"
- **现场校准建议**：提示用户在设置中校准系统时间，或确保所有设备使用同一时间源
- 偏差超过 5 秒时显示提示，可关闭

### 可靠性与无障碍
- 输入校验、字段级错误提示、空状态与恢复提示
- LocalStorage 损坏恢复与数据版本（当前 `version: 2`）
- 响应式布局；`prefers-reduced-motion` 与手动关闭动效
- 键盘可操作、焦点可见、对话框焦点回收、`role` / `aria-*` 语义
- 加载完成后核心功能离线可用，无后端与外部资源依赖

## 技术栈

React 18、TypeScript、Vite 5、Tailwind CSS 3、Lucide Icons、LocalStorage、Vitest + Testing Library。

## 快速开始

环境要求：Node.js ≥ 18（建议 20+），npm ≥ 9。

```bash
npm install
npm run dev          # 本地开发，默认 http://localhost:5173
```

生产构建与本地预览：

```bash
npm run build        # 类型检查 + 构建到 dist/
npm run preview      # 预览构建产物，默认 http://localhost:4173
```

## 部署静态站

1. 执行 `npm run build`，产物位于 `dist/`。
2. 将 `dist/` 整体上传到任意静态托管（Nginx、GitHub Pages、Netlify、Vercel、对象存储等）。
3. Vite 已配置 `base: './'`，可部署在域名根路径或子目录，无需服务端路由重写（单页应用，无前端路由）。
4. 建议通过 HTTPS 访问：Fullscreen API 与部分浏览器能力要求安全上下文（`localhost` 除外）。

Nginx 示例：

```nginx
server {
    listen 80;
    server_name your-domain.example;
    root /var/www/eventclock-v2/dist;
    index index.html;
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

## 数据与隐私

- 存储键：`eventclock.v2.state`
- 损坏数据备份键：`eventclock.v2.corrupt.<timestamp>`
- 数据结构：`{ version, events, activeEventId, settings, roadshow }`
- **所有数据仅保存在当前浏览器**，不上传服务器；清除浏览器数据会同时删除活动
- **跨设备需手动导出/导入**：每台设备独立保存，修改不会自动同步到其他设备
- 导入会替换当前活动与设置；建议先导出备份

## 时间精度说明

- 倒计时与路演计时都只保存 **绝对时间戳**，渲染时用 `Date.now()` 实时计算剩余时间，不做本地累加，因此刷新、标签页切换和系统休眠恢复后不会漂移
- 页面每 250ms 刷新一次显示；在 `visibilitychange`、`focus`、`pageshow` 时立即重新校准
- 时区仅影响展示与时间输入解析，不参与倒计时运算
- **设备时间校准**：应用会检测本地时间与网络时间偏差，提醒用户校准；纯静态前端无法主动纠正系统时钟，跨设备统一计时需依赖设备自身时间同步（NTP）

## 自定义品牌与文案

编辑 `src/config/branding.ts`：

```typescript
export const DEFAULT_BRANDING: BrandingConfig = {
  eventTitle: 'TRAE on Campus',          // 主标题
  eventSubtitle: 'AI Coding Hackathon',  // 副标题
  organization: '四川大学',                // 主办方

  phases: {                               // 活动阶段名称（可选）
    registration: '签到与组队',
    hacking: '编程时间',
    submission: '作品提交',
    presentation: '路演展示',
    judging: '评审中',
    ceremony: '颁奖典礼',
  },

  roadshow: {
    defaultTeamName: '参赛队伍',          // 路演默认队伍名
    sessionLabel: '路演环节',             // 路演环节标签
  },

  visual: {
    primaryColor: '#93adff',              // 主色调
    accentColor: '#6c8cff',               // 强调色
    particleCount: 50,                    // 粒子数量
    animationIntensity: 'medium',         // 动画强度 low/medium/high
  },
};
```

修改后重新构建即可生效。

## 已知限制

- 未进行公网部署；仅提供静态构建产物与部署说明
- 提醒仅在页面打开时触发，不发送系统级推送
- 提示音依赖浏览器音频策略，首次交互前可能静音
- **数据与提醒均在单一浏览器内**；跨设备需手动导出 / 导入 JSON
- **时间校准依赖设备**：纯静态前端无法主动纠正系统时钟，跨设备统一计时需依赖设备时间同步（NTP）
- 极端夏令时「跳过的时间」由浏览器时区规则近似处理

## 仍需现场验证的事项

1. **路演投影大屏**：投影仪分辨率适配（1920×1080）、队伍名称长度、超时提示可见性
2. **时间校准提示**：现场网络环境下能否正常检测时间偏差
3. **多设备协作**：确认现场操作人员理解"单设备保存、跨设备需手动导出/导入"
4. **动画性能**：投影设备或低性能设备上，代码粒子流、网格动画是否流畅（可在设置中关闭动效）
5. **视觉验收**：打开大屏后，观众能否一眼认出"TRAE 黑客松"与当前阶段
